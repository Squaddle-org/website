Diese Website

squaddle.org ist eine statische Website: Sie besteht ausschließlich aus HTML-, CSS- und (nur auf der Einladungsseite /j/*) einer kleinen JavaScript-Datei, die lokal im Browser läuft. Es werden keine Cookies gesetzt, kein Local Storage für Tracking verwendet, keine Analyse- oder Marketing-Skripte eingebunden und keine Inhalte von Drittanbietern (Schriften, CDNs, Fonts) nachgeladen.

Server-Logs

Der Webserver speichert zu Betriebs- und Sicherheitszwecken (z. B. Fehlersuche, Abwehr von Missbrauch) minimale technische Zugriffsprotokolle: Zeitpunkt, angeforderter Pfad, HTTP-Statuscode und User-Agent. IP-Adressen werden nicht protokolliert. Diese Protokolle werden nur kurz aufbewahrt und nicht mit anderen Daten verknüpft.

Die Einladungsseite (/j/*)

Der geheime Teil eines Einladungslinks (alles nach dem #) wird von Browsern grundsätzlich nicht an den Server gesendet. Unser JavaScript auf dieser Seite liest diesen Teil ausschließlich lokal, um ihn auf Wunsch per "Link kopieren" in Ihre Zwischenablage zu legen — er wird nicht übertragen, nicht protokolliert und nicht an Dritte weitergegeben.

Die Squaddle-App und der Relay-Server

Diese Seite betrifft nur die Website squaddle.org. Räume, die Sie in der Squaddle-App anlegen, sind Ende-zu-Ende-verschlüsselt: Weder diese Website noch ein Relay-Server kann Ihre Ideen, Abstimmungen oder Pläne lesen. Ein Relay sieht zur technischen Zustellung notwendige Metadaten (z. B. Raum- und Gerätekennungen, Zeitstempel), aber keine Klartextinhalte. Sie können jederzeit einen eigenen Relay-Server betreiben, wenn Sie keinem fremden Betreiber vertrauen möchten.

Ihre Rechte

Da diese Website selbst praktisch keine personenbezogenen Daten erhebt, dürfte ein solches Anliegen am ehesten die App bzw. einen genutzten Relay-Server betreffen. Wenden Sie sich hierzu an die oben genannte Kontaktadresse. Sie haben außerdem das Recht, sich bei der für Ihren Wohnsitz zuständigen Datenschutz-Aufsichtsbehörde zu beschweren.

This website

squaddle.org is a static site: plain HTML and CSS, plus (only on the invite fallback page /j/*) a small JavaScript file that runs locally in your browser. No cookies are set, no local storage is used for tracking, no analytics or marketing scripts are embedded, and no third-party assets (fonts, CDNs) are loaded.

Server logs

For operational and security purposes (troubleshooting, abuse prevention) the web server keeps minimal technical access logs: timestamp, requested path, HTTP status code and user agent. IP addresses are not logged. These logs are kept only briefly and are not combined with any other data.

The invite page (/j/*)

The secret part of an invite link (everything after the #) is never sent to any server by the browser in the first place. Our JavaScript on this page reads it only locally, to optionally put it on your clipboard via "Copy invite link" — it is never transmitted, logged, or shared with anyone.

The Squaddle app and relay server

This page covers only the squaddle.org website. Rooms you create in the Squaddle app are end-to-end encrypted: neither this website nor any relay server can read your ideas, votes, or plans. A relay does see the technical metadata needed to deliver data (such as room and device identifiers, and timestamps), but never plaintext content. You can run your own relay server at any time if you'd rather not trust anyone else's.

Your rights

Under the GDPR you have the right to access, rectify, erase, restrict the processing of, port, and object to processing of personal data concerning you. Since this website itself collects essentially no personal data, such a request more likely concerns the app or a relay server you use — please reach out via the contact address above. You also have the right to lodge a complaint with the data protection authority responsible for your place of residence.
